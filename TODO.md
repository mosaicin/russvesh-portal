# Результаты проекта

- [x] Главная страница представляет книгу и навигацию по ключевым разделам портала.
- [x] Информационные материалы о книге и двух томах не воспроизводят охраняемый полный текст.
- [x] Самостоятельные аннотации и критические материалы отделены от цитат и снабжены источниками.
- [x] Языки переводов заметно выделены: узбекский, таджикский, армянский, румынский/молдавский и аварский.
- [x] Есть внешние ссылки для проверки доступа и библиографических сведений с нейтральной правовой маркировкой.
- [x] Правовой раздел запрещает публикацию полного текста, сканов, PDF/DJVU, аудиокниги и полного перевода без разрешения.
- [x] Форма запроса разрешения содержит контакт, язык, объём, цель и подтверждает, что это локальный черновик, а не автоматическое разрешение.
- [x] Сайт адаптивен, доступен с клавиатуры и содержит `manus-routes.json`.
